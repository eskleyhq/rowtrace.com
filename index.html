What you get

Structured Smartsheet aligned folders

Navigating to a file in a backup is just like navigating to a file in a Smartsheet. Just drill down. Every Smartsheet row has its own folder.

A CSV and an HTML page listing every file with its row, version, size, URL for linked attachments, who uploaded it, and when it was uploaded.

Backups run on days and at times you choose. Keep as many days as you like. Only changed files download, and every run is a complete copy.
