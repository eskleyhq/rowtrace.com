Getting started

Getting started

Sign up for a trial code, download Rowtrace, paste the code and a Smartsheet API token, choose what to back up and where, and run.

Before you start

  • A Windows 10 computer you're signed in to when backups run.
  • A Rowtrace trial code. Sign up and Eskley emails you the code and the download link.
  • A Smartsheet account on smartsheet.com.
  • A Smartsheet API access token. In Smartsheet: Account → Personal Settings → API Access → Generate new access token. Copy it; Smartsheet shows it once.
  • Somewhere to save: a local drive, a OneDrive folder, a network drive or a SharePoint library.

Rowtrace backs up what the token's user can see. Use a token from an account that's shared to everything you want backed up; Your token and your data explains which account to use.

Your first backup

  1. Open Rowtrace

    Download Rowtrace.exe from the link in your sign-up email and double-click it. It opens in its own window.

    The first time, Windows may show Windows protected your PC. Choose More info, check that the publisher reads Eskley LLC, then choose Run anyway.

  2. Sign in

    Rowtrace opens on Sign in. Paste the trial code from your email.

  3. Connect

    Paste your token and choose Connect to Smartsheet. Rowtrace saves the token on this computer, encrypted to your Windows user, so you paste it once.

  4. Choose what, when and where

    Choose New backup:

    • Select items. Tick the workspaces, folders, sheets and reports to back up.
    • When. Now, once to try it out, or On a schedule: every day or on the weekdays you pick, at a time you choose.
    • Where. Pick a save location and a folder layout: By row number, flat works for any sheet; By primary column, keep row hierarchy names folders from the first column and nests them like the sheet.
    • Review, then Back up now or Save schedule.

    Backing up a large account for the first time? Choose Plan a first backup. It counts what you have and spreads the first full copy over the nights you allow.

  5. Open the result

    Choose Open backup folder. Each run is a new folder named for its date and time. History lists every run.

Keep scheduled backups running

  • Stay signed in. Lock the screen instead of signing out.
  • Keep the computer awake and plugged in at the scheduled time.
  • If you move Rowtrace.exe, save each schedule again.
