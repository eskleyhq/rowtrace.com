Rowtrace and Smartsheet's backup

Smartsheet's backup puts every uploaded attachment in one folder. Rowtrace files each attachment under its row and keeps a manifest that maps every file back.

Side by side

Smartsheet's backupRowtrace
AttachmentsOne folder for the whole backup1A folder per row, holding that row's attachments
Which file came from which rowNot recorded1A manifest maps every file to its row and records what the row said at the time
Folder and workspace structureNot kept: "Workspace backups include sheet data, not the workspace's structure"3Kept: your folders become folders
How oftenWeekly, Saturday to Monday4Every day, or weekly on the days you pick, at a time you choose
Who can schedule itWorkspace owners and admins on Business or Enterprise4Anyone with an API token, for what that token can see
Earlier versions of an attachmentNot mentioned in Smartsheet's backup help3Kept beside the current one
Linked files (Drive, OneDrive, Box, URLs)Left out3Listed in the manifest with their links; the files themselves stay where they are
ReportsLeft out3Report data exported to Excel on whole-workspace backups
Checked after it's writtenNone documented in Smartsheet's backup help3Every file checked against the size Smartsheet reported
Where it livesA zip you download, then wherever you put it2Your folder, from the start
Runs without your computer onYes, Smartsheet generates it4No. Your Windows computer has to be on and signed in at the scheduled time
